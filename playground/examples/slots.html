Slots: vln-inlet / vln-outlet

The <template vln-template="'card'"> below is a reusable frame with three mount points: a title (via vln-vars), a default slot for the body, and a named 'actions' slot for the footer. Each card below fills them differently.

Notice how directives inside inlets (vln-loop, vln-on:click, vln-text) all resolve against caller state — the template is just the frame; reactivity flows through the caller's graph.
