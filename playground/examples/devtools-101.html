Guided tour

1 — Pick an element

Ctrl+Shift+P, hover a priority badge, click. The popover lists the states that own the node, every directive bound to it, each expression, the state paths it reads, and the mutation that last changed each value. All at once, from a click.

2 — Hidden fan-out

hotspots → Record, toggle the theme dropdown 3 times, Stop. The badge class 'priority-' + task.priority + ' theme-badge-' + theme fires once per visible row per toggle. Three top-level writes produced 3 × rowCount re-renders — invisible fan-out across sibling rows that happen to share one dep. Move theme-badge-X to the container; one write, one effect.

3 — The innocent debug line

See the gray line below the list? Looks like a cheap stat summary. Record, toggle one checkbox, Stop. debugLine ran — it reads JSON.stringify(this.tasks), so Velin captured a dep on every field of every task. Any mutation anywhere re-serializes the whole list for one display character.

4 — Clean code, loud footprint

Record, click ✓ all done, Stop. filteredTasks and debugLine each fired once per task. The code is a plain for loop assigning t.done = true — nothing looks wrong, but every assignment synchronously flushes every dependent effect. Open devtools-101.js and uncomment the Velin.getController(this).batch(() => { … }) wrapper around the loop. Record again — the per-expression counts collapse from N to 1.

5 — What watches this?

dependents, path root.theme, scope wide. Every expression that would re-run if you changed the theme, with its node and estimated cost. Narrow scope answers "which effects on this exact state read this path"; wide descends into composed children (every row's state). You can't get this answer from source grep — iteration deps aren't visible until runtime.

6 — The invisible leak

Click details on any task, close the modal (× or Esc), repeat five times. leaks → run scan: detachedStates and detachedEffects both grew. Each modal mounts a nested Velin.bind(); closing only removes DOM. The state tree is still alive, bindings still registered. Uncomment the Velin.unbind(nestedState) line in openDetails — scan goes clean.

7 — Push it until signals fire

load 500, then type into the filter. Toasts appear bottom-right. The filter uses an O(n²) highlight match that crosses the 16ms frame budget on 500 rows, tripping W002 slow-expression. signals opens the persistent inbox — each entry has a human-written what / why / what to do, and drills into explainEffect for recentRuns, reads, and whyDidThisRun.
