State-driven enter/leave

Velin doesn't ship a transitions system — reactivity is enough. Toggle a boolean flag, animate against it with vln-class, and swap the underlying state after the CSS duration. Two patterns cover almost every case: a boolean flag around vln-if, and per-item flags on a keyed vln-loop.

Fade a panel

One boolean (panelLeaving) drives the CSS. On hide, we flip it, wait 300 ms, then flip panelShown = false. Fifteen lines of state, no library help.

Slide-out list items

Each item owns a leaving flag. remove(id) sets it to true, then splices the item out of the array after the CSS duration. The keyed loop keeps the row in place while it fades, so the transition plays where you'd expect.

The same pattern extends to route swaps (delay setting a route path) or template swaps (delay setting a vln-fragment id). Anywhere you'd want an animation, insert a flag + a delay.
