Welcome to Velin

A lightweight, reactive JavaScript library that makes building interactive UIs with plain HTML and vanilla JavaScript incredibly simple.

What is Velin?

Velin is a reactive state management library that lets you build dynamic, responsive applications using HTML directives and plain JavaScript—no build steps, no JSX, no complicated framework overhead.

Just write vln- directives in your HTML, connect them to your state, and Velin handles all the reactivity. When your state changes, the UI updates automatically.

🎯

Directives

Add reactive behavior to your HTML with simple vln- attributes like vln-text, vln-if, vln-on:click.

⚡

Reactivity

Your UI stays in sync with your state automatically. Change a value in JavaScript and watch your HTML update instantly.

🚀

Simple

No complex setup. No node_modules bloat. Load the script, write your HTML, and you're done. That's it.
