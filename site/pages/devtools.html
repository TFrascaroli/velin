Velin Devtools

An in-page companion that answers the questions you can't get from DOM inspection, console logs, or Chrome's Performance tab: which effects a state path triggers, where a leak is still rooted, which mutation drove the slow run, which binding is quietly re-firing.

Six questions it answers

  • Where does this value come from? Pick any node, see every state that owns it, every directive bound to it, the expression each evaluates, and the mutation that last changed each value.
  • What watches this path? Query a state + path, get every effect that would re-run — including iteration deps that source grep misses.
  • What's actually expensive? Record a session, interact with the page, stop — see every expression that ran, how often, with the mutation that drove it. Attribution is at the Velin expression level, not the JS function level.
  • Why did this effect just run? Opens an effect's recent-runs trace, the paths it reads, and which path triggered the latest run.
  • Am I leaking? On-demand scan surfaces effects still bound to nodes removed from the document, state roots detached from the DOM, and hook subscribers that were never released.
  • Something crossed a threshold. A persistent signals inbox with human-written explainers for thrash, long effects, and orphan spikes — each entry drills into the relevant surface.

Try it

The playground ships a dedicated guided tour: a working task tracker with five realistic, invisible-to-the-eye bugs. Each step points at the specific devtools surface that reveals it, and the fixes for batching and leak teardown are commented right in the source so you can toggle them on and watch the metrics collapse.

From the sidebar in the playground, pick Devtools 101 at the bottom. Press Ctrl+Shift+V to open the panel. Follow the seven steps.

Attaching to your own page

Build Velin with __DEV__=true and load velin-devtools.dev.js after your Velin bundle. The companion tree-shakes to zero in production builds. 

<script src="velin.dev.js"></script>
<script src="velin-devtools.dev.js"></script>

Status

Devtools is 0.2.0-alpha. The hook API and the six question surfaces are stable; UI polish is the current focus.
